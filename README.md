# Flowday

Flowday is a Flutter Android productivity planner prototype focused on building and reviewing balanced daily routines.

The app starts with local database choices, lets users create a personal profile, previews emoji-based timetable grids with connectors for continuous tasks, supports task completion review, mood selection, scoring, streaks, and profile stars.

Always read `app-info.md` before changing product behavior so implementation stays aligned with the original app concept.
